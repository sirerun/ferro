## Ordered implementation steps

1. Implement a deterministic result builder from the frozen execution record. Keep outcome, validation and billing state independent. Failed validation cannot emit succeeded.
2. Map typed errors to the frozen status/reason/retry table; preserve partial results and metrics on failure. Unknown effects forbid automatic retry.
3. Enforce UTF-8 byte limits for summaries and inline output. Oversized results use an artifact reference through an explicitly injected bounded artifact sink; this path performs I/O and must propagate storage failures; never silently truncate accepted JSON.
4. Redact secrets via explicit safe diagnostic fields, not a best-effort regex over arbitrary provider dumps. Do not change legacy RunTaskOutput.
