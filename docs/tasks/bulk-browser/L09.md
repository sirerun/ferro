Use the RUNBOOK handoff template. Mark ready-for-review only when the required behavioral tests and full owning-package tests pass and git diff --check passes. Do not claim installed/live verification. Commit only owned files on the assigned branch; do not merge, push, deploy or start another task unless instructed.

A deterministic typo or formatting fix does not count as an attempt.
