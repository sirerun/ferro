## Ordered implementation steps

1. Implement the profile resolver against the frozen Profile and CredentialResolver contracts. Resolve a configured name to an immutable revision; reject unknown names before resolving a credential.
2. Validate endpoint URL, nonempty exact model identifier and configured limits. Do not accept task-provided URLs or keys. Copy mutable maps/slices before returning resolved state.
3. Support the explicit legacy profile mapping supplied by G01. Do not edit environment loading or side-panel routes; return the mapping implementation to the integrator.
4. Return public profile descriptions with names/capabilities only. Never serialize credential values. Use injected private-store access; do not read the operator's real configuration in tests.
