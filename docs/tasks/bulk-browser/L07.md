## Ordered implementation steps

1. Implement private local receipt storage with opaque generated IDs, atomic writes, owner binding and frozen maximum sizes. Use t.TempDir in every storage test.
2. Persist admitted execution identity before work; finalize terminal result and artifact metadata atomically according to G01. Detect conflicting task ID/request digests; do not replay browser work.
3. On reopen, in-flight entries become outcome_uncertain. Reads require the supplied trusted owner identity and bounded offsets/lengths. Never accept filesystem paths from callers.
4. Provide explicit cleanup callable by the operator, preserving active/unreconciled receipts. Do not add timers, daemons, scheduler loops or public listeners.
